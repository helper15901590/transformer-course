打分 QKᵀ：
谁和谁像

本关目标

D1 说“拿 Q 去比 K”，D2 说 Q、K 是投影出来的向量。现在终于要用它们了：拿每个词的 Q，去和每个词的 K 做点积，得到一张“谁和谁像”的分数表。这一步叫 QKᵀ，是 A2（点积）和 A3（矩阵乘法）的直接应用。

Guess first

一句话有 3 个词，每个词都有一个 Q、一个 K。要让每个 Q 都和每个 K 比一次，一共要比几次？

（先选一个，下面揭晓。）

①

理解：这一关在说什么

Understand

D1 说“拿 Q 去比 K”，但一直没真的比。这关就真比。

“比”用什么？用点积（A2 学的：两个向量一位一位地乘、再相加，越大越像）。而句子有很多个词，每个词都有 Q 和 K，所以是“每个 Q × 每个 K”。

n 个词，就有 n 个 Q 和 n 个 K。每个 Q 都要和 n 个 K 各比一次，所以一共比 n × n 次，得到一张 n × n 的分数表。

这张表，就是“谁和谁像”的原始分数——它是后面一切（缩放、softmax、加权求和）的起点。

回到“先猜”

答案是 9 次。3 个 Q × 3 个 K = 9 次，得到 3×3 的表。n 个词就是 n×n。你猜对了吗？

一句话记住

QKᵀ = 拿每个词的 Q 去点积每个词的 K，得到一张 n×n 的“谁和谁像”分数表。

!

易混点：先拎清楚

Watch out
最容易搞混的三处

① 右上角那个小 ᵀ 是“转置”，不是新运算。它只是把 K 的矩阵横竖翻一下，好让形状对得上、能做乘法。别被它吓到。

② 分数表第 i 行第 j 列 = 词 i 的 Q 和词 j 的 K 的点积。行 = 谁在“问”，列 = 问到了谁。

③ 这些还只是“原始分”，不是注意力权重。还没做缩放、还没 softmax——那两步分别在 D4、C3 处理。别把分数直接当成最终权重。

②

学习：要掌握的点

Learn

把动作写清楚：每一个 Q，去和每一个 K 做点积。第 i 个词的 Q 和第 j 个词的 K 的点积，就是分数表第 i 行第 j 列的数。

跟着走一遍（3 个词的小例子）

句子“我 爱 猫”，每个词一个 2 维的 Q 和 K（这里让 Q 和 K 取一样，是为了好看清“自己最像自己”）：

我：Q=[1,0]　K=[1,0]
爱：Q=[0,1]　K=[0,1]
猫：Q=[1,1]　K=[1,1]

算几个格子给你看（点积 = 一位一位乘、再相加）：

我·我 = 1×1 + 0×0 = 1（自己和自己）
我·爱 = 1×0 + 0×1 = 0（一点不像）
猫·猫 = 1×1 + 1×1 = 2（自己和自己，最大）

把 9 个格子都算完，就得到这张 3×3 分数表（对角线 = 自己和自己，都偏大）：

分数表长这样（3×3）

虚线对角 = 自己和自己 · 数字越大 = 越像

记住一个规律：对角线上的数（自己和自己）通常偏大——因为一个词和自己的点积，等于每个数平方再相加，天然是正数、还往往最大。这就是“一个词最像自己”。
