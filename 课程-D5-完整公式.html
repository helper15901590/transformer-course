①

理解：这一关在说什么

Understand

把之前学的零件，全拼进一条公式。

Attention(Q, K, V) = softmax( Q Kᵀ√dₖ ) V

别被它吓到——它就是把四个你已经会的东西接起来：

  • QKᵀ（D3）：每个 Q 点积每个 K，得分数表。
  • ÷√dₖ（D4）：缩放，稳住分数。
  • softmax（C3）：把每一行变成加起来 100% 的权重。
  • ×V（下面讲）：按权重，把各个词的 V 加权求和，得到新向量。
回到“先猜”

答案是 4 步：打分 → 缩放 → softmax → 加权求和。你猜对了吗？

!

易混点：先拎清楚

Watch out
最容易搞混的三处

① 顺序不能乱。一定是 打分 → 缩放 → softmax → 加权。尤其“缩放要在 softmax 之前”。

② 最后一步“×V”才是真正“取内容”。前面的打分、缩放、softmax 都是在算“该看重谁”；×V 才把内容按比例混进来。

③ 结果还是“每个词一个新向量”。注意力输出和输入长得一样（还是 n 个向量），只是每个向量里已经混进了上下文。

②

学习：要掌握的点

Learn

最后一步 ×V（加权求和） 还差一句话没说透：把每一行的权重，拿去和各个词的 V 做“按比例混合”。

跟着走一遍（最后一步怎么算）

假设“我”这一行的权重是 [0.40, 0.20, 0.40]（对“我 / 爱 / 猫”各看多少）。三个词的 V 是：我=[1,0]、爱=[0,1]、猫=[1,1]。

“我”的新向量 ＝ 0.40×[1,0] ＋ 0.20×[0,1] ＋ 0.40×[1,1]
＝ [0.40, 0] ＋ [0, 0.20] ＋ [0.40, 0.40] ＝ [0.80, 0.60]

看：这个新向量里，混进了“猫”和“爱”的信息。这就是“每个词读懂了上下文”。

把 4 步连起来，就是完整公式。下面实践节，带你从头到尾亲手走一遍。

Q1完整公式 attention(Q,K,V) = softmax(QKᵀ/√dₖ)·V，正确的顺序是？选择题

A打分 → 缩放 → softmax → 加权求和
Bsoftmax → 打分 → 缩放 → 加权求和
C缩放 → 打分 → 加权求和 → softmax
D加权求和 → softmax → 打分 → 缩放
看参考
选 A。顺序不能乱：先打分 QKᵀ，再缩放 ÷√dₖ，再 softmax，最后 ×V 加权求和。

Q2真正“把内容取走、混进来”的，是哪一步？选择题

A打分 QKᵀ
B缩放 ÷√dₖ
Csoftmax
D×V 加权求和
看参考
选 D · ×V。前三步都在算“该看重谁”，只有 ×V 才按权重把各词的 V 混进来。

Q3判断：注意力算完，输出还是 n 个词各一个向量，只是每个向量里已经混进了上下文。判断题

✓对
✗错

Q4【用得上】权重是 [0.5, 0.5]，两个词的 V 是 [2,0] 和 [0,4]，加权求和结果是？选择题

A[1, 2]
B[2, 4]
C[1, 1]
D[0, 0]
看参考
选 A · [1,2]。0.5×[2,0] + 0.5×[0,4] = [1,0] + [0,2] = [1,2]。

Q5【用得上】softmax 应该在缩放的之前还是之后？选择题

A之前（先 softmax 再缩放）
B之后（先缩放再 softmax）
C无所谓，先后一样
看参考
选 B。必须先缩放、再 softmax——缩放就是为了让 softmax 别“押死”。公式里也是 QKᵀ/√dₖ 整个包在 softmax 里。
这一关，带走三句话
  1. 完整公式：attention(Q,K,V) = softmax(QKᵀ/√dₖ)·V。
  2. 4 步顺序：打分 → 缩放 → softmax → 加权求和（顺序不能乱）。
  3. 前三步算“该看重谁”，×V 才是真正取内容；输出还是 n 个“读懂了上下文”的向量。
🎉 阶段 D 回顾 · 你已打通注意力的计算

学到这里，你应能一口气说出整条链：

每个词变出 Q/K/V（D1–D2）→ 拿 Q 比 K 得分数 QKᵀ（D3）→ 除以 √dₖ 缩放（D4）→ softmax 成权重（C3）→ 乘 V 加权求和（D5）

这就是 attention(Q,K,V) 的全部。后面 E、F 阶段，就是在这块“注意力”之上做文章（多头、位置、拼整机）。
