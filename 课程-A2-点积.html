点积：
两个向量怎么算“像不像”

本关目标

上一关我们把东西变成了数字串（向量）。这关要回答：两串数字摆在一起，怎么算出它俩像不像？你会学一个动作叫“点积”。它正是后面“注意力”最核心的一步。用纸笔就行。

?

先猜一猜（再看答案）

Guess first

有苹果 [7, 2, 6]、葡萄 [9, 1, 2]、柠檬 [2, 9, 4]。凭感觉猜：下面三对里，哪一对“最像”？

（记着你的选择，下面会用“点积”算出真正的答案。）

①

理解：这一关在说什么

Understand

先问一个很具体的问题。

上一关把水果变成了数字串：苹果 [7, 2, 6]、葡萄 [9, 1, 2]。现在问：苹果和葡萄，像不像？光盯着六个数字，很难说清，更给不出一个“分数”。

我们需要一个能算出“像不像分数”的笨办法。它简单得出奇，叫 点积：把两串数字一位对一位地乘起来，再把乘出来的结果全加起来。

苹果 [7, 2, 6]　和　葡萄 [9, 1, 2]
7×9 = 63　　2×1 = 2　　6×2 = 12
再加起来：63 + 2 + 12 = 77

这个 77，就是苹果和葡萄的“点积”。再换两对算算：苹果·柠檬 = 14+18+24 = 56；葡萄·柠檬 = 18+9+8 = 35。

三个数排一排：苹果·葡萄 = 77，苹果·柠檬 = 56，葡萄·柠檬 = 35。77 最大，正好是“苹果和葡萄最像”（俩都又甜又不酸）；35 最小，正好是“葡萄和柠檬最不像”（一个甜一个酸）。数字自己把“像不像”讲出来了。

一句话记住

点积 = 一位一位地乘，再全部加起来，得到一个数。这个数越大，两个向量就越“像”；越小（哪怕变成负数），就越“不像”。

回到“先猜”

如果你猜的是“苹果 · 葡萄”，你猜对了——它俩的点积最大（77）。

!

易混点：先拎清楚

Watch out
最容易搞混的三处

① 点积算出来是“一个数”，不是“一串数”。两串数字进去，一个数字出来——这个数就是“像不像分数”。

② 点积大，不一定等于“更像我”。它还受“数字大小、数字串多长”影响：方向差不多但整体更大的，点积也会更大。所以严格说，它衡量的是“合拍程度 × 大小”。（后面注意力的“缩放”，就是为了抵消“数字串太长”带来的影响。）

③ 点积 = 0，不等于“完全不认识”。意思是“互相抵消了”，大致是“没什么关系”。

②

学习：要掌握的点

Learn

把刚才的动作写成式子：

a · b　=　a₁b₁ + a₂b₂ + … + aₙbₙ

念作“a 点 b”。别怕这串符号，它说的就一句话：第 1 位乘第 1 位，第 2 位乘第 2 位，……最后全加起来。两串数字的个数要一样，才配得上。

算出来的这个数，怎么理解？记住三种情况：

  • 是个挺大的正数 → 两串数字老是“一起大”，很合拍，很像。
  • 差不多是 0 → 你大我小、你正我负，抵消了，基本没关系。
  • 是负数 → 老是“一个正一个负”，对着干，很不像。

为什么“乘起来再相加”能看出像不像？这么想：如果两串数字在同一个位置上都偏大，乘出来就是个大正数，加进去贡献大；要是一个大一个小甚至一正一负，乘出来就小、甚至为负，反而把总分往下拉。越合拍，总分越高。

一个特例，很有用

一个向量和它自己做点积，等于把它每个数平方再加起来，结果一定是正数，而且很大——因为它和自己“最合拍”。（D 阶段的自注意力会用到。）
